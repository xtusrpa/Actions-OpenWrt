非OPenwrt固件，下载固件后解压出img格式，下载DiskImg镜像写入工具，制作好pe，将固件和刷机工具放进pe盘，pe启动设备删除硬盘所有分区，用DiskImg工具写入即可关机移除pe启动设备。

qemu-img convert -f raw -O qcow2 DSM.img DSM.qcow2  #镜像转换

qm importdisk 102 DSM.qcow2 local-lvm               #镜像挂载
